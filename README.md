# Albor Solar — Landing page

Landing para anuncios de Meta (mobile first). Es un único archivo `index.html`, sin dependencias.

## Antes de publicar, editá:
1. **`CONFIG` (al final de `index.html`)**: número de WhatsApp, teléfono, email, zonas y supuestos de la calculadora.
2. **`ALBOR_PIXEL_ID`** (en el `<head>`): ID de tu píxel de Meta. Eventos: `PageView`, `Contact` (clic en WhatsApp/llamar) y `Lead` (formulario).
3. **Reseñas, puntaje de Google y "+150 casas"**: reemplazar por datos reales.
4. **Fotos**: buscá los comentarios `EDITAR` en el HTML (hero, obras, og-image).
5. **Precios de los packs.**

## Publicar
Funciona en cualquier hosting estático (Netlify, Vercel, GitHub Pages, Cloudflare Pages): subí `index.html` (y la carpeta `fotos/` si agregás imágenes).
